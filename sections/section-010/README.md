# Metrics And Alerting With Prometheus

This section has 11 independent module labs. Each follows its preparation lesson and contains 3–5 tasks around one outcome. Allow 10–15 minutes of task work per lab; cluster startup, rollouts and telemetry collection add time. The capstone combines the module skills.

**Curriculum item covered:** Implementing Monitoring, Alerting, Logging, and Tracing Solutions

| Module | Practical outcomes |
| --- | --- |
| Scrape Workloads With ServiceMonitor And PodMonitor | Scrape Pods With A PodMonitor; Repair ServiceMonitor Discovery; Extend Raw Prometheus Pod Discovery; Scale From A Queue Metric |
| Query Metrics With PromQL | Repair An Error Ratio Recording Rule; Repair A Latency Percentile Recording Rule |
| Alert With PrometheusRule And Alertmanager | Create And Verify An Alerting Rule; Route An Alert To Its Receiver; Silence A Maintenance Alert; Inhibit A Related Warning Alert; Repair Route Precedence And Grouping |

Use the playground for the reading examples. Start each graded lab in its own environment, submit after checking the result, then remove it before resuming the playground. A later lab does not depend on an earlier lab's changes.
