# Introduction

Before you start the first module, take ten minutes for this introduction. It tells you what this course trains you to do, how to get your machine ready, and who builds the course. Some CLI tools need to be installed on your machine to follow the lessons and complete the exercises in this course. These three short pages introduce those tools and help you prepare for the chapters ahead.

The introduction contains several pages, which we recommend reading in order:

- **Welcome to the Course** explains who the course is for, what you will learn, how the course is structured, and how to navigate each page.
- **Get Your Machine Ready** covers the tools you need to install, the commands you will use, and how to troubleshoot common setup problems.
- **How This Course Is Made** explains how the content is written and reviewed, who maintains it, and how to report mistakes.

Once you have completed the introduction, you are ready to begin the course.
