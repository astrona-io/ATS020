# Diagnosing And Remediating Incidents

This section has 9 independent module labs. Each follows its preparation lesson and contains 3–5 tasks around one outcome. Allow 10–15 minutes of task work per lab; cluster startup, rollouts and telemetry collection add time. The capstone combines the module skills.

**Curriculum item covered:** Diagnosing and Remediating Platform Issue and Incident Scenarios

| Module | Practical outcomes |
| --- | --- |
| Triage And Fix Failing Workloads | Schedule A Pending Workload; Repair A Crashing Process; Repair A Failing Liveness Probe; Repair An OOMKilled Workload; Repair An Image Reference |
| Diagnose And Fix Broken Platform Components | Repair A Webhook Service Port; Renew An Expired Webhook Certificate; Restore The Prometheus Operator; Recover A GitOps Source Path |

Use the playground for the reading examples. Start each graded lab in its own environment, submit after checking the result, then remove it before resuming the playground. A later lab does not depend on an earlier lab's changes.
