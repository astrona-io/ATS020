# Module Lab Coverage

Each row connects a lesson with an independent lab and its live checks. The 39 module labs below cover the rollout beyond the seven section-030 pilot labs. The six existing setup/capstone labs retain their integration role.

Module labs contain 3–5 tasks and target 10–15 minutes of learner work. Startup, deployment history generation, rollout and telemetry waits add time. Every listed lab has a negative starting-state check, a reference solution and lifecycle testing in GitHub Actions.
